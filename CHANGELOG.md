# Changelog

All notable changes to SoundGround will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Admin dashboard with logs, statistics, and metrics
- Centralized TypeScript types system
- Centralized constants management
- Structured logging utility
- Comprehensive test utilities
- GitHub Actions CI/CD pipeline
- API route and component test suites

### Changed
- Optimized pre-commit hooks (removed slow build step)
- Enhanced .cursorrules with production standards
- Consolidated documentation structure

### Fixed
- Various linting warnings in components

## [0.1.0] - 2025-10-09

### Added
- Initial release
- SoundCloud profile viewing
- Audio player with HLS support
- Queue management
- SQLite-based caching
- OAuth 2.0 authentication
- Search functionality
- External platform link detection (Bandcamp, Hypeddit, Beatport)
